Caveats

  • Eleven of the twenty-six planned tasks are implemented, so the overall score describes this subset, not the full benchmark.
  • Each task had a 20-minute wall-clock cap, below the 120-minute task budget declared in the task manifests. Slow but correct approaches may be cut off.
  • The run used a dirty working tree at commit d494e5e, with uncommitted harness changes.
  • The local subprocess backend was used instead of the container backend.
  • Runtimes are taken from artifacts; model wall-clock time is estimated from result timestamps, not measured by the worker.
  • One seed per task. Replicate variance is not yet estimated.
  • The comparison confounds model capability with agent-harness behaviour.
  • MiMo-V2.6-Flash hit the cap on ten of eleven tasks. A timeout is labelled as a timeout and keeps any partial score the harness could grade, which for MiMo was zero. It is never silently rewritten into an ordinary zero.

Related, not merged
