Reading a comparison

Sections are equal weight

The overall score is the mean of section scores. A model that is strong in single-cell analysis but weak in networks cannot hide the weak section behind many single-cell tasks.

Few tasks per section

Most sections currently contain one or two implemented tasks. Section scores are therefore coarse, and a single task failure moves the overall score substantially.

Colour is redundant

Heat cells encode score with both a number and a sequential background. The table remains readable in greyscale, with a screen reader, or with CSS disabled.

No cross-edition comparison

This view is scoped to First pilot. Protcols, datasets and task versions differ between editions, so a cross-edition comparison would be misleading.
